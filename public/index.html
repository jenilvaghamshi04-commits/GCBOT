What Orbit can actually discover

BOT API REALITY CHECK
Available*

Group administrators

List admins when the bot is a member and has access to that group. A hidden/anonymous admin may not expose a personal identity.

Public signals

Owner, CEO, CTO, moderators

Can be matched only when the person self-identifies in public group messages, linked channels, or official project pages. Not verified by Telegram.

Unavailable

Full member directory

The Bot API does not let a bot enumerate all group members. A bot can inspect particular users it already knows about.
